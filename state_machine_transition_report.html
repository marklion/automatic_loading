事件触发条件总表（15 个事件）

事件名称枚举值触发来源 / 条件触发函数
急停 AL_SM_EVENT_EMERGENCY_SHUTDOWN 操作员调用急停接口 emergency_shutdown()
切换到手动模式 AL_SM_EVENT_SWITCH_TO_MANUAL_MODE 操作员调用手动切换接口 switch_to_manual_mode()
重置到初始状态 AL_SM_EVENT_RESET_TO_INIT 操作员调用重置接口 reset_to_init()
触发就绪 AL_SM_EVENT_GET_READY 门禁/闸机推送车辆信息，且物料名称能匹配套件 trigger_sm(vehicle_info) → pre_process_stuff
车辆到达 AL_SM_EVENT_VEHICLE_COME 激光雷达车头坐标 front_x ∈ [front_min_x, front_max_x] push_vehicle_front_position(front_x)
车辆停留 AL_SM_EVENT_VEHICLE_STAY 判定状态内，车头连续 40 个 125 ms 周期（约 5 s）保持在目标区间 al_sm_state_judge 内部定时器
车辆离开 AL_SM_EVENT_VEHICLE_LEAVE 激光雷达车尾坐标 tail_x ∈ [tail_min_x, tail_max_x] push_vehicle_tail_position(tail_x)
车辆前移过度 AL_SM_EVENT_VEHICLE_OVER_FORWARD 车尾坐标 tail_x ∈ (tail_max_x, tail_call_x]（车辆前冲超出装车区但未消失） push_vehicle_tail_position(tail_x)
车辆消失 AL_SM_EVENT_VEHICLE_DISAPPEAR 车尾坐标 tail_x > tail_call_x（车辆完全驶离检测范围） push_vehicle_tail_position(tail_x)
达到装载量 AL_SM_EVENT_LOAD_ACHIEVED 地磅实时重量 ≥ max_load（配置的最大装载量） push_cur_load(cur_load)
装载量清零 AL_SM_EVENT_LOAD_CLEAR 地磅实时重量 == 0（车辆驶离地磅后归零） push_cur_load(cur_load)
料位达满 AL_SM_EVENT_REACH_FULL SO-PID 80 ms 定时器：分段输出 ∈ {0, 1}，且 (max_load − 当前重量) ≥ 1 t sm_start_so_pid 内部 80 ms 定时器
溜槽就绪 AL_SM_EVENT_LC_READY 即将开始状态：IO 下发溜槽落控制后等待 stay_second 秒延时到期 al_sm_state_begin 内部定时器
异常空车 AL_SM_EVENT_EXCEPTION_EMPTY SO-PID：分段输出 = 3（料面远低于目标）且偏移变化速度 < −12 m/s（料面快速下降） sm_start_so_pid 内部 80 ms 定时器
无货 AL_SM_EVENT_NO_STUFF SO-PID：落料率 > 0 且重量 80 ms 内增量 < 0.02 t，持续 > 140 次（约 11 s）判定无料 sm_start_so_pid 内部 80 ms 定时器
